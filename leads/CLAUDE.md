# Rules for the leads folder

- Every record is **fictional**. Emails must end in `@example.com`.
- Never add a real person, a real email, or a phone number.
- Never send anything to these addresses. They exist only to test segmentation and
  personalization. The send-guard hook blocks them anyway.
- Segments:
  - `browsers` - signed up, never ordered. Curious, need a reason to start.
  - `bookworms` - order often. Want depth, early access and staff picks.
  - `gift-givers` - mostly buy for other people. Want easy gifting and nice wrapping.
- If a column is `unknown`, write around it. Never guess a genre for a reader.
