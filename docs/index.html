🏮 Lantern Lane Books

A practice email studio for The Lantern Box, a monthly book subscription.

by Maqsood Ahmad Farooqi

Brand voice

Warm, specific, unhurried. One idea and one invitation per email.

Launch sequence

Four emails over 12 days, plus 12 versions for browsers, bookworms and gift-givers.

Send-guard

A Claude Code hook that only lets email reach Resend test addresses or the owner.

Review

A rule-based reviewer with schema-shaped JSON, and a read-only reviewer agent.

studio-kit

The same guard, reviewer and skill, packaged as a reusable plugin.

Checks

All automated checks run on every push with GitHub Actions.
